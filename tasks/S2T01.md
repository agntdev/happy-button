# S2T01 — Add Second Button with Sequence Tracking

**Difficulty:** medium
**Weight:** 0.3000 (share of project budget)
**Reward:** 30 BTTN + 0.03 TON

Implement a second button that tracks alternating clicks between both buttons. The sequence must count 3 alternations (e.g., Button 1 → Button 2 → Button 1 → Button 2 → Button 1 → Button 2) to trigger the celebration. Files: `index.html`, `script.js`. Test by clicking buttons in order and verifying sequence counter.
